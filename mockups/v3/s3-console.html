Working notes

Why a portfolio that behaves like a tool

Because that is the job. Most of what I have shipped is not a page you read top to bottom — it is a surface somebody works in all day, where the hierarchy has to survive real data and the keyboard path has to be as good as the mouse one.

So this layout is the argument. A persistent index, one stage, state in the URL, full keyboard control, and transitions that tell you which direction you moved. If a portfolio is a work sample, it may as well sample the work I actually do.
